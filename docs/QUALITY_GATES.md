## Управляемые Android-сценарии RC

Release ARM64 собран **без личного config-файла**, с несекретным тестовым ключом
и `CAT_API_BASE_URL=https://<временный-хост>/acceptance/v1`. Тестовый сервер
отдаёт синтетические породы и собственную иконку как фото. TLS обычный,
сертификат действительный; обходов и изменений production-кода нет.
Инструменты и команды — [tool/acceptance](../tool/acceptance/README.md).

Все **21** сценарий повторно прошёл на RC:

| Группа | Результат |
| --- | --- |
| `feed`, 3 | Шесть быстрых нажатий → один голос/запрос; свайп с нажатиями → один голос/запрос; детали/Back/restart не запрашивают другого кота или фото |
| `errors`, 12 | HTTP 500/429, пустой/испорченный/неверного типа JSON, отсутствие породы; фото 404/неверные байты; таймаут метаданных и фото; 401/403. Ошибка понятна, повтор сохраняет голос, фото не вызывает новый поиск, авторизация без бесполезного повтора |
| `catalog`, 3 | HTTP 500, плохой JSON, пустой список: ошибка и восстановление без сброса кота/лайков или нового поиска |
| `lifecycle`, 1 | Уход на Home во время запроса и возврат: готовая карточка, один голос/запрос |
| `network`, 2 | Потеря сети сохраняет голос и каталог; offline startup и повтор восстанавливают сохранённого кота, без двойного лайка/нового поиска |

Медленные ответы задерживались на 16 секунд при таймауте приложения 10 секунд;
сообщения фиксировались примерно через 12.3–12.4 секунды с учётом UIAutomator.
После включения радио инструмент ожидает VALIDATED default network Android.
В журнале UID приложения по всем процессам не найдены `FATAL EXCEPTION`,
`Unhandled Exception`, `setState() called after dispose`, `RenderFlex overflowed`.

Сырые результаты текущего прогона, XML, PNG и журнал запросов хранятся вне Git:
`/private/tmp/hw1-prefinal`. По завершении возвращается обычный APK;
тестовый сервер, туннель и временный AVD останавливаются.

## Предыдущая приёмка того же приложения

Полный предыдущий журнал относится к `4203423`, инструменты — `35abbb8`;
`lib` совпадал с `984abdb`. Уже проверены обычная свежая установка, кнопки/свайпы
0 → 1 → 1 → 2 → 2, сохранение прокрутки после Back, 21 управляемый сценарий,
нет/неверный ключ отдельными release-сборками и запуск через CLI.
APK без ключа показывал инструкцию без HTTP-запросов; APK с выдуманным ключом
и настоящим API — явную ошибку авторизации без повтора. В текущем RC изменения
касаются защиты открытия деталей во время свайпа и метаданных версии.

Для оформления `984abdb` проверены 320×568 dp с текстом ×2 на Android,
неподвижные доступные кнопки, четыре экрана и launcher-иконка. Размер/шрифт
восстановлены; adaptive/monochrome-ресурсы и PNG Android/Web/macOS проверены.
Прежние Web/macOS-сборки и настоящий Web refresh описаны в полном журнале;
новая нативная macOS-сборка в этом прогоне не заявляется.
