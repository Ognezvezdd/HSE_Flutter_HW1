# Кототиндер — спецификация

Актуальный контракт версии `1.0.1`. Источник: [ДЗ №1](https://georgfed.github.io/hse-flutter-course/assignments/hw1.html).
Траектория — с агентом. [Исходный план до реализации](https://github.com/Ognezvezdd/HSE_Flutter_HW1/blob/7273733/docs/SPEC.md)
сохранён в истории Git. Изменения требований фиксируются до соответствующего кода.

## Границы и устройство

Четыре экрана: коты, детали кота, каталог пород, детали породы. Платформа сдачи —
Android; Web пригоден для разработки. Аккаунты, собственный сервер и история
лайков не входят в работу. По замечанию автора R2 добавлено локальное сохранение.

`Cat` и `Breed` — типизированные модели; HTTP и JSON находятся вне виджетов.
Состояние принадлежит `State`, данные передаются конструкторами, действия —
callback. `HomeScreen` хранит ленту и счётчик; `CatApi` — каталог на время сессии.
`IndexedStack` сохраняет вкладки, `ScrollController` — позицию каталога.

## Лента и сохранение

- Первая установка: 0 лайков. Карточка появляется после загрузки данных и фото;
  порода и фотография относятся к одному коту. Демонстрационных котов нет.
- Лайк/пропуск доступны кнопками и свайпами вправо/влево. Один принятый голос —
  один переход. Лайк увеличивает счётчик, пропуск оставляет его прежним.
- На время сохранения и запроса действия блокируются. Повтор после ошибки
  следующего запроса не начисляет лайк снова. Сбой фото повторяет только фото
  того же кота; незагруженную карточку оценить нельзя.
- `SharedPreferencesAsync` хранит единый JSON-снимок: версия, счётчик, текущий кот.
  Ключ API и байты фото не сохраняются; пространство хранения учитывает URL API.
- Принятый голос сначала сохраняет счётчик и отсутствие текущего кота, затем
  запрашивается следующий. Полученный кот сохраняется до показа карточки.
- Refresh/перезапуск восстанавливает счётчик и кота; перезапуск во время запроса
  сохраняет голос и продолжает загрузку. Web-хранилище привязано к origin.
- Ошибка записи блокирует следующий запрос; повтор записи не удваивает лайк.
  Ошибка чтения не затирает данные; сброс повреждённого снимка требует подтверждения.

## Навигация и сведения

Тап по фото или «О породе» передаёт текущего кота и фото в прокручиваемые детали.
Нового случайного кота при этом нет. Пока карточка движется при свайпе, детали
не открываются; после отменённого свайпа тап работает. Back сохраняет ленту.

Каталог загружается через `/breeds`, сортируется по названию и кешируется в памяти.
Одновременные обращения объединяются, ошибка не кешируется. Детали получают
выбранный `Breed`; Back возвращает список к прежней прокрутке. Смена вкладок
не сбрасывает кота, лайки или каталог и не начинает лишний запрос.

Общий блок сведений показывает описание, происхождение, темперамент, срок жизни,
группу, вес и доступные дополнительные поля API. Основные отсутствующие поля —
«Нет данных», отсутствующие дополнительные разделы не создаются. Рейтинги
бесплатного API могут отсутствовать; значения не выдумываются. Старые снимки
дополняются по ID/уникальному имени из каталога без смены кота и счётчика.

## Сеть, ошибки и конфигурация

TheCatAPI: `/images/search?has_breeds=1&limit=1&mime_types=jpg,png` и `/breeds`.
`CAT_API_KEY` и `CAT_API_BASE_URL` читаются через `String.fromEnvironment`;
адрес по умолчанию — `https://api.thecatapi.com/v1`. Настоящий ключ исключён из Git.
Только HTTPS, обычная проверка TLS; таймаут запроса и фото — 10 секунд.

Обрабатываются отсутствие сети, HTTP-ошибки, пустой/неверный JSON, отсутствие
породы, сбой фото и хранилища. Понятное сообщение и подходящий повтор сохраняют
счётчик. Нет пустых `catch`; после `await` учитывается жизненный цикл виджета.
По R1 `/breeds` проверяет авторизацию перед поиском; при коте без породы доступ
перепроверяется. 401/403 объясняют необходимость исправить ключ и перезапустить,
без бесполезного повтора. Без ключа показана инструкция, запросов нет.

Фото загружается штатным `NetworkImage`, ключ на CDN не передаётся. Для Web
используется `WebHtmlElementStrategy.prefer` из-за CORS CDN, без подмены источника.

## Оформление и приёмка

Русский интерфейс; данные API допускаются на языке источника. Единая тема,
собственная иконка, состояния загрузки/ошибки, прокрутка длинных текстов.
Кнопки закреплены вне прокручиваемой карточки и доступны на 320×568 при тексте ×2.
Метки: `cat_card`, `cat_breed_name`, `like_button`, `dislike_button`, `like_counter`,
`breeds_tab`, `retry_button`; счётчик содержит число.

[Quality gates](QUALITY_GATES.md): запуск и свежая установка Android, кнопки/свайпы,
быстрые действия, четыре экрана/Back, восстановление, ошибки/повтор, подмена HTTPS
API через параметры сборки, анализ, APK, визуальное и авторское ревью.
Сдача: README из восьми разделов, точный commit, APK в GitHub Release и медиа той
же версии. README содержит авторское объяснение устройства приложения.
