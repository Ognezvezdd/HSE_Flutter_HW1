# Проверки release Android с управляемым API

Эти инструменты не входят в приложение. Сервер отдаёт только синтетические породы
и собственную иконку как тестовую фотографию. Настоящий ключ TheCatAPI не нужен.
Проверки выполняются на отдельном тестовом AVD: они перезапускают приложение,
голосуют и временно отключают сеть этого устройства.

Из корня проекта создайте вне Git `state.json` с корневым HTTPS-адресом сервера:

```json
{"public_url": "https://YOUR-TEST-HOST"}
```

Запустите сервер, передав абсолютные пути к состоянию и журналу запросов:

```sh
python3 tool/acceptance/api_server.py --state /tmp/hw1-state.json --log /tmp/hw1-requests.jsonl
```

Выполненный прогон использовал временный HTTPS URL Cloudflare Quick Tunnel:
`cloudflared tunnel --url http://127.0.0.1:8877`. После получения URL укажите его
в `public_url`. Сервер не предоставляет доступ к файлам проекта или управлению
режимами по сети. Управление — только локальным JSON. Приложение использует HTTPS
с обычной проверкой сертификата; исключения TLS и cleartext-настройки не нужны.

Сборка тестового варианта без личного конфигурационного файла:

```sh
flutter build apk --release --dart-define=CAT_API_KEY=acceptance-test-key --dart-define=CAT_API_BASE_URL=https://YOUR-TEST-HOST/acceptance/v1
```

Установите полученный APK на тестовый AVD. Для проверки чистой установки обычного
приложения сначала используйте APK с TheCatAPI и пустое устройство. Сборки с
тестовым сервером предназначены только для проверки и не публикуются в Release.

Группы `feed`, `errors`, `catalog`, `lifecycle`, `network` запускаются по очереди:

```sh
python3 tool/acceptance/check_mock.py feed --adb /PATH/TO/adb --serial emulator-5560 --state /tmp/hw1-state.json --log /tmp/hw1-requests.jsonl --output /tmp/hw1-results
```

Замените `feed` на следующую группу и подставьте свои пути/ID устройства. Нужны
Python 3 и adb, дополнительных пакетов Python нет. На выходе — строки результатов,
`results.jsonl`, XML доступности и снимки. В журнале сервера нет значений ключей.
Группа `network` дожидается VALIDATED default network Android перед повтором;
само включение Wi-Fi ещё не означает восстановление соединения.

Проверяется количество запросов: один принятый голос вызывает один запрос;
повтор фото не запрашивает нового кота; детали/Back/восстановление не меняют кота;
сбои каталога не сбрасывают ленту. Медленный ответ задерживается на 16 секунд,
чтобы проверить установленный в приложении таймаут 10 секунд.

После прогона остановите сервер и туннель и верните APK, собранный с обычной
конфигурацией. Фактические результаты: [QUALITY_GATES.md](../../docs/QUALITY_GATES.md).
